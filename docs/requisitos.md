# Requisitos del Sistema SmartERP

## Descripción

SmartERP es un sistema ERP para la administración de una pequeña empresa.

El sistema permitirá gestionar usuarios, productos, clientes, proveedores, compras y ventas.

---

# Usuarios del sistema

## Administrador

Funciones:

- Gestionar usuarios.
- Gestionar productos.
- Gestionar clientes.
- Gestionar proveedores.
- Consultar reportes.

## Empleado

Funciones:

- Registrar ventas.
- Consultar productos.
- Gestionar clientes.

---

# Módulos

## Seguridad

- Inicio de sesión.
- Autenticación mediante JWT.
- Control de permisos.

## Inventario

- Crear productos.
- Editar productos.
- Eliminar productos.
- Consultar existencias.

## Ventas

- Registrar ventas.
- Generar detalle de venta.
- Consultar historial.
